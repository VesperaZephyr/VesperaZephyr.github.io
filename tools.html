妙妙工具

  • WolframAlpha — 计算知识引擎
  • 强力算一元积分 — 含步骤
  • Desmos — 在线函数图形绘制
  • GeoGebra — 动态几何与代数工具
  • Mathigon — 一个有趣的数学网站, 它的数学时间线很惊艳
  • Overleaf — 在线 LaTeX 编辑器
  • CodeCogs LaTeX 公式生成器 — 在线编辑并生成公式
  • Mathcha — 一个可视化在线编辑 LaTeX 的网站, 亮点是可以可视化绘制 TikZ
  • q.uiver — 在线 LaTeX 交换图绘制
  • 在线 LaTeX 表格绘制
  • Beamer 主题矩阵 — 快速预览与选择 Beamer 模板
  • 在线 Markdown 编辑
  • MinerU — PDF 转 Markdown, 公式与表格识别
  • PDF24 Tools — 免费的全能 PDF 在线工具箱
